# AURA AI Evaluation

## Scope
The included benchmark contains 30 synthetic customer messages across delivery, refund, cancellation and billing intents. It is intended to validate portfolio behavior and regression safety.

## Metrics
- Intent classification accuracy
- Governance gate sanity check
- Policy grounding availability

## What this does not prove
The benchmark is too small and synthetic to establish production accuracy, safety or ROI. A production evaluation program should include representative historical cases, adjudicated labels, policy-version testing, adversarial prompts, PII scenarios, hallucination checks and human acceptance scoring.
